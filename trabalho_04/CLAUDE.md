# CLAUDE.md — Agent context for trabalho_04

## What this project is

A 4-page statistical analysis report (Typst → PDF) on the CongNaMul soybean sprout dataset.  
`analysis.py` produces all figures and computed values; `report.typ` imports them — no hardcoded numbers anywhere in the report.

## File roles

| File | Purpose |
|---|---|
| `analysis.py` | Single entry point: loads data, generates all figures, computes stats, writes outputs |
| `report.typ` | Typst report; imports `outputs/results.toml` and `outputs/tbl_*.typ`; includes SVGs from `figs/` |
| `outputs/results.toml` | Scalar results (counts, p-values, R², correlations) |
| `outputs/tbl_desc.typ` | Descriptive statistics table |
| `outputs/tbl_norm.typ` | Normality test table (all 5 features including weight) |
| `outputs/tbl_models.typ` | OLS vs RANSAC coefficient table |
| `figs/fig0_dataset_overview.jpg` | Static image, not generated by script |
| `figs/fig1_distributions.svg` | KDE + histogram for 4 morphological features |
| `figs/fig2_qqplots.svg` | Normal Q-Q plots for 4 morphological features |
| `figs/fig3_correlation.svg` | Pearson correlation heatmap (weight-complete subset) |
| `figs/fig4_ransac.svg` | OLS vs RANSAC fitted-vs-actual scatter |
| `figs/fig5_weight_dist.svg` | KDE + histogram for weight |
| `references/congnamul.bib` | BibTeX citation for the dataset paper |
| `references/partial_transcript.md` | Dataset description from lecture transcript |
| `references/ictccameraready.pdf` | Full dataset pre-print |

## Key design rules

- **No hardcoded values in `report.typ`** — every number must come from `outputs/`.  
  Add new scalars to `results.toml` via `write_toml()` in `save_outputs()`.  
  Add new tables as `.typ` files via `make_booktabs_table()`.
- **`REMOVE_OUTLIERS = True`** uses a 3×IQR fence on the 4 morphological features only.
- **Deduplication** is by sample ID parsed from the filename (`_NNN.jpg` suffix).
- **Weight subset** (`df_w`): rows where `weight != -1`. All weight-related analysis uses `df_w`.
- `FEATURES` lists the 4 morphological features; weight is handled separately throughout.
- `SHORT_LABELS` includes `"weight"` and is used for table row labels.

## Report layout (4-page budget)

1. Dataset Overview — overview image + prose
2. Descriptive Statistics — `tbl_desc` + `fig1_distributions`
3. Normality Testing — prose + `tbl_norm` + `fig2_qqplots`
4. Correlation and Regression — weight dist & correlation heatmap side-by-side (grid), `tbl_models`, `fig4_ransac`, prose
5. Conclusions

The weight distribution (`fig5`) and correlation heatmap (`fig3`) share a row via `#grid(columns: (1fr, 1fr))` to conserve page space.

## Build

```
make run    # uv run python analysis.py && typst compile report.typ
make clean  # rm figs/*.svg
```

The Linux Libertine font warning from `typst compile` is harmless — Typst falls back to a system font.

## Adding new analyses

1. Write a `fig_*` or compute block in `analysis.py`.
2. Save figures to `figs/` as SVG; save scalars to `results.toml` sections; save tables as `outputs/tbl_*.typ`.
3. Reference in `report.typ` using the existing import pattern — no literals.
4. Check page count stays ≤ 4.
