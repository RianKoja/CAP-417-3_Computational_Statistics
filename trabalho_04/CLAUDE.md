This repository is a homework assignment for the course "Estatística Computacional" at INPE. 

It shall create a report in pdf format, indicating the author (Rian Koja) using typst and be at most 4 pages long, but rich in beautiful graphs and statistical analysis.

check README.md for more information.

a description of the dataset is available at trabalho_04/references/partial_transcript.md and the full pre-print in pdf is available at trabalho_04/references/ictccameraready.pdf

remember that I don't care about figures.

any numerical result generated should be saved in the outputs/ folder, either in the result.toml file for small parameters or in a .tpy file for tables, so it cna be easily imported in the final report.typ file.

report.typ must have no hardcoded values, all values should be imported from the outputs/ folder.
