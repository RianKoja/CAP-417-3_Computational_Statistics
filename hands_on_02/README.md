# Hands-on 02 — Agent Benchmark & Discussion

This project evaluates and compares two independent solutions for the CAP 417 Hands-on 02 assignment, generated by **Claude Code** and **Gemini CLI**.

## Project Structure

- `claude-code/`: Solution and results from Claude Code.
- `gemini-cli/`: Solution and results from Gemini CLI.
- `benchmark/`: 
  - `run_benchmark.py`: Script to programmatically compare results.
  - `benchmark_report.md`: Detailed algorithmic and numerical comparison.
  - `quality_scorecard.md`: Evaluation of code quality.
  - `moments_comparison.csv`: Computed differences in statistical moments.
- `discussion/`:
  - `discussion.md`: Theoretical answers based on the empirical results.
- `Analysis.ipynb`: Jupyter notebook version of the benchmark analysis.
- `run_all.sh`: Shell script to execute both solutions and the benchmark.

## How to Run

### Prerequisites
- Python 3.8+
- Libraries: `numpy`, `scipy`, `pandas`, `matplotlib`

### Running the Full Pipeline
To execute both agent solutions and generate the benchmark report:
```bash
./run_all.sh
```

### Running the Analysis Notebook
To interactively explore the comparison:
```bash
jupyter notebook Analysis.ipynb
```

## Summary of Findings
- Both agents successfully implemented the colored noise generation and shuffling analysis.
- **Claude Code** utilized more modern NumPy APIs (`Generator`) and optimized FFT functions (`rfft`).
- **Gemini CLI** provided additional visualization of statistical moments in table form.
- Numerical results are highly consistent between both implementations, confirming that shuffling preserves marginal moments and that Red noise exhibits biased kurtosis estimates for finite samples.
